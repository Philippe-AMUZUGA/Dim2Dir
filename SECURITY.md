# Politique de sécurité

Pour signaler une vulnérabilité, ne pas ouvrir de signalement public : ouvrir un signalement privé de vulnérabilité depuis l'onglet « Security » du dépôt GitHub (« Report a vulnerability »), en décrivant le problème, les versions concernées et, si possible, un fichier ou une commande qui le reproduit.

Une réponse est apportée dès que possible. Les correctifs sont publiés dans la dernière version.
